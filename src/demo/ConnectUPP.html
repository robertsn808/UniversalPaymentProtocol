1) Create Account

Sign up or log in to manage your API key. Buyers cover all fees; recipients receive the full amount.

2) API Key

Create or paste an API key to call UPP without code.

3) Connect This Device

Register your browser as a UPP device.

Device ID: not registered

4) Start Receiving (Payout Account)

Create a white‑label payout account so you can receive funds. Fully branded — processor hidden.

Account ID: not created

5) Onboarding (KYC/KYB)

Provide identity or business details required to enable charges and payouts. Data stays on UPP.

6) Add Payout Method (Bank)

Add a bank account for payouts (tokenized on server).

7) My Balance & Payouts

View your account status, balances, and recent payouts.

5) Accept a Payment (Test)

Runs a test payment. Buyer pays fees; you receive the full amount.

6) Send to Another UPP User

Pick a connected device and send a payment. Buyer pays fees.

8) Pay Recipient by Email (Routed)

Charge the buyer and route funds to a recipient’s connected account. Buyer covers all fees. Default platform fee: 1.5%.

9) Pay by Card (Direct, Processor Hidden)

Card data is sent only to UPP servers over HTTPS and tokenized server‑side (processor fully hidden). Buyer covers all fees. Enable PCI_COMPLIANCE_MODE on the server.

Notes: This interface uses your API key to call secured endpoints. Payments run in test mode unless you configure live keys. No third‑party branding is shown to end users.
