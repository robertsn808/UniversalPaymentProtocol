Example database sync (add to PaymentController):
```php
protected function recordLocalTransaction(int $userId, string $type, array $data): void
{
    DB::table('w_transactions')->insert([
        'user_id' => $userId,
        'type' => $type,
        'amount' => $data['amount'],
        'transaction_id' => $data['transactionId'],
        'status' => 'completed',
        'created_at' => now(),
    ]);

    DB::table('w_users')
        ->where('id', $userId)
        ->update(['balance' => $data['newBalance']['totalBalance']]);
}
```

# Visa Direct Credentials Required

Based on analysis of the Visa Direct implementation in UPP, here are the exact credentials needed:

## Required Credentials for Visa Direct

### 1. mTLS Certificates (Primary Authentication)
- **Client Certificate**: Your Visa-provided client certificate in PEM format
  - Environment: `VISA_CERT_PATH=/path/to/visa_client_cert.pem`
- **Private Key**: Matching private key for the client certificate
  - Environment: `VISA_KEY_PATH=/path/to/visa_client_key.pem`
  - CRITICAL: Must match the client certificate
- **CA Certificate Chain**: Visa's Certificate Authority chain
  - Environment: `VISA_CA_PATH=/path/to/visa_ca.pem`

### 2. x-pay-token Credentials (Alternative/Additional Auth)
- **API Key**: Your Visa Developer project API key
  - Environment: `VISA_API_KEY=your_xpay_api_key`
- **Shared Secret**: Cryptographic key for HMAC signing
  - Environment: `VISA_SHARED_SECRET=your_xpay_shared_secret`

### 3. Business Configuration
- **Acquiring BIN**: 6-digit bank identification number
  - Environment: `VISA_ACQUIRER_BIN=408999` (sandbox example)
  - PROVIDED BY: Your sponsor bank/acquirer
- **Business Application ID**: Transaction category identifier
  - Environment: `VISA_BAI=PP` (P2P payments)

### 4. Optional Basic Auth (Some Endpoints)
- **User ID**: `VISA_USER_ID=your_visa_user_id`
- **Password**: `VISA_PASSWORD=your_visa_password`

## Certificate Types You Need
1. **Visa Development Platform Root CA**: Yes - part of the CA chain
2. **Intermediate Certificate**: Yes - typically bundled in the CA chain
3. **DigiCert Global Root CA**: Likely yes - Visa uses DigiCert infrastructure
4. **Your Client Certificate**: Yes - unique to your Visa Developer project
5. **Your Private Key**: Yes - matches your client certificate

## Setup Priority
Start with mTLS first - it's the primary authentication method. The implementation supports dual authentication strategies with mTLS as primary and x-pay-token as alternative/additional authentication.
